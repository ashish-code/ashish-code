## 🧠 About Me

I'm a Senior Data Scientist specializing in **deep learning for computer vision** and **medical image analysis**. My work spans no-reference image quality assessment, GAN-based image synthesis, entropy-driven image metrics, and geo-spatial localization in GPS-denied environments. I've collaborated with institutions including **Ohio State University** and the **National Geo-spatial Intelligence Agency (NGA)**.

I build systems where ML is the core — not just a library call — and I care deeply about rigorous evaluation, transfer learning, and production-ready model design.
